# Examples

Real `peyk` outputs and common invocations. The `report*.json` / `report.md`
files in this folder were generated by the commands below on an Apple M3 / 16 GB
laptop — run the same commands on your machine to get results for *your*
hardware.

## Generate these files

```bash
peyk --json                 > examples/report.json        # machine-readable
peyk --markdown examples/report.md --use-case chat        # shareable Markdown
peyk --deep --json          > examples/report-deep.json   # + native probe fields
```

- [`report.json`](report.json) — full recommendation as JSON (hardware + ranked models).
- [`report.md`](report.md) — the same as a Markdown report.
- [`report-deep.json`](report-deep.json) — with `--deep`, adds `cpu_model`,
  `ram_type`, `ram_speed_mtps`, `ram_channels`, and `mem_bandwidth_source`.

## Common recipes

```bash
# Best all-round model for chat, favoring Turkish + English support
peyk --use-case chat --languages tr,en

# Pick a coding model and size it for a 32k context window
peyk --use-case coding --context 32768

# On a GPU server: aggregate multi-GPU VRAM and verify sizes live
peyk --cross-check --top 10

# Discover trending GGUF models not in the bundled catalog
peyk --discover

# CPU box: get a *measured* memory bandwidth (needs dmidecode)
sudo peyk --sudo
```

## Use in scripts / CI

`--json` makes `peyk` composable. A few `jq` one-liners:

```bash
# List every model that fits comfortably, best first
peyk --json | jq -r '.models[] | select(.tier=="FITS") | "\(.overall)\t\(.model) \(.params_b)B \(.quant)"' | sort -rn

# The single top recommendation
peyk --json | jq -r '[.models[] | select(.tier!="NO_FIT")] | max_by(.overall) | .model_id'

# Fail a CI job unless at least one quality model (score >= 75) fits
peyk --json | jq -e '[.models[] | select(.tier=="FITS" and .scores.quality>=75)] | length > 0' >/dev/null \
  && echo "capable model available" || echo "hardware too small"

# Detected hardware summary
peyk --deep --json | jq '.hardware | {cpu_model, ram_type, ram_speed_mtps, accelerator, vram_total_gb, mem_bandwidth_gbs, mem_bandwidth_source}'
```
